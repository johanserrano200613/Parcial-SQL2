# Proyecto de Base de Datos para un E-commerce

## Descripción

Base de datos para una tienda en línea desarrollada en MySQL. Gestiona productos, categorías, proveedores, clientes, inventario, ventas y detalle de ventas, junto con consultas avanzadas, funciones, seguridad, triggers, eventos y procedimientos almacenados.

## Integrante

Johan Alejandro Serrano Rivera

## Requisitos

- MySQL Community Server 8.0.46
- DBeaver

## Orden de ejecución

1. `01_Esquema_y_Datos.sql`
2. `02_Consultas_Avanzadas.sql`
3. `03_Funciones.sql`
4. `04_Seguridad.sql`
5. `05_Triggers.sql`
6. `06_Eventos.sql`
7. `07_Procedimientos_Almacenados.sql`

Los archivos deben ejecutarse en ese orden para crear la base de datos, cargar los datos y después implementar la lógica avanzada.
